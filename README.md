# Gorkhali Tara - Season 5 Singing Reality Show

A full-stack web application for Gorkhali Tara Season 5 - Nepal's premier vocal reality show. Built with React + Vite frontend and Express.js backend.

## Features
- Live voting system with Razorpay/Stripe payment gateway integration
- Real-time vote updates via Server-Sent Events (SSE)
- Admin dashboard for contestants, episodes, judges, and settings management
- YouTube episode embedding
- Leaderboard with live standings
- Contestant profiles with audio previews

## Tech Stack
- **Frontend**: React 19, Vite 8, TailwindCSS 3, Lucide React
- **Backend**: Express.js 5, Node.js
- **Payments**: Razorpay, Stripe (simulated)

## Getting Started

```bash
npm install
npm run dev      # Start frontend
npm run server   # Start backend
```
